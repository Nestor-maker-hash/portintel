# PortIntel

A Rust command-line tool for defensive TCP service reconnaissance.

## Features

- Resolve hostnames to IPv4 addresses.
- Scan a specified TCP port range.
- Identify common services by port.
- Probe selected services for banners and version indicators.
- Inspect selected HTTP responses.
- Check TLS protocol negotiation on supported ports.
- Generate timestamped text reports.

## Requirements

- Rust and Cargo
- Network access to an authorized test target
